- will need conda/python environment with packages in requirements.txt  (email me if issues)

To setup the code, follow these steps:

1. clone the repository however you want to:

Lewis McCallum's code:
git clone https://github.com/LewisSMcCallum/CMacIonize.git (anonymous download, can fork if you want)

Meg's code:
git clone https://github.com/megblackburn/CMacIonize.git

2. mkdir build
3. cd build
4. cmake .. -DCMAKE_PREFIX_PATH=$CONDA_PREFIX -DHYDROGEN_ONLY=true | tee output_from_cmake.txt
5. make -j 16 (if own laptop probably just 'make', leave out -j)
6. (optional) make check

Code should now be compiled!

7. cd build/rundir/benchmarks/stromgren/

8. Run test:
 ../../CMacIonize --params stromgren.param --threads <number of parallel threads>

Then go through tutorials:
 https://bwvdnbro.github.io/CMacIonize/tutorials/

Basics of CMacIonize:

- Density structure:
  -> DensityFunction:
       type: Homogeneous
       * this will give a homogeneous grid of whatever temperature, density and neutral fraction H you set *
  -> some common options:
      => DiscPatch: The density setup described in McCallum et al 2024
      => HydroEquilibrium: Set up to be in equilibrium with the SILCC & Li et al. 2019 potential
      => DiscPatchHydroEquilibrium: Set up to be in equilibrium with the McCallum et al 2024, Vandenbroucke & Wood potential used
      => SILCC: Set up to match the 
- External potential
- Photon source

- all files controlling simulation are in src folder

Example parameter files are here:

- bursty_sfr_tallbox.param.used-values contains all possible parameters
- bursty_sfr_tallbox.param is an example of a parameter file I'm currently using
- I've added quick comments about the most important parameters for tallbox sims

Important files for Stellar winds:
- MixedDrivingPhotonSourceDistribution.hpp or BurstyPhotonSourceDistribution.hpp
- SupernovaHandler.hpp

Important for Ionizing Spectra:
- PhotonSourceSpectrumFactory.hpp
- PlanckPhotonSourceSpectrum.cpp and *.hpp are probably good templates for form - can use whichever <keyword>PhotonSourceSpectrum.cpp/.hpp file fits the spectra you want to implement best 
- keywords are all displayed in PhotonSourceSpectrumFactory.hpp - these are all options to set in the param file


Temperature Calculations:

- the static ionisation codes take the 'do temperature calculation' parameter within the TemperatureCalculator section 
- the task-based RHD code has 2 options: 
                => split the calculation into heating and cooling seperately
                    ==> Hydro:
                          do explicit heating: true
                    ==> TaskBasedRadiationHydrodynamicsSimulation:
                          do radiative cooling: true

                => do the computation together
                  ==> TaskBasedRadiationHydrodynamicsSimulation:
                        do explicit temperature calculation: true

              ** if one way is being used the other parameters for the other way must be set to false! **

              ** if metals are not included, in hydrogen only mode:
                ==> TaskBasedRadiationHydrodynamicsSimulation:
                      use cooling tables: true
